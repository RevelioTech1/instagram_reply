# Иордань — ответы на комментарии

Бот для аккаунта [Instagram @iordani925](https://www.instagram.com/iordani925/). Он читает комментарии под постами мастерской и, когда человек просит цену, размер, наличие, доставку или ссылку, отвечает карточкой товара с [iordani.com](https://iordani.com).

Цена берётся только из карточки на сайте. Если артикул неясен, бот не выбирает изделие наугад и просит номер. Комплименты и реакции остаются без ответа.

## Запуск

```bash
npm install
npm run dev
```

Панель открывается на [http://127.0.0.1:4317](http://127.0.0.1:4317).

Во входящих уже лежат учебные комментарии. Их можно разобрать, поправить текст и сохранить. В Instagram они не отправляются.

`npm test` проверяет, что цена, артикул и отказ отвечать на комплимент работают так, как задумано.

## Как он понимает пост

1. В подписи или в комментарии ищется артикул (`Б-КО-338`, `B-KO-338`, `03-21-596`).
2. Если артикулов несколько, комментарий сужает выбор: «а серёжки почём?» не получит цену кольца.
3. Если артикула нет, сравнивается название. Общие имена вроде «Спаси и Сохрани» не схлопываются в одну цену.
4. Пост без артикула можно закрепить вручную на странице «Посты».

В подпись поста лучше сразу ставить артикул. Тогда ответ почти всегда попадает в нужную карточку.

## Подключение Instagram

Вход такой же, как у сервисов для постов: кнопка «Войти через Instagram» открывает окно самого Instagram. Публичная страница Facebook не нужна. Аккаунт @iordani925 должен быть профессиональным.

Один раз создайте приложение в [списке приложений Meta](https://developers.facebook.com/apps/) (войти можно личным аккаунтом Meta). Витрина «Платформа Instagram» приложение не создаёт. В мастере выберите сценарий «Manage messaging & content on Instagram», затем внутри приложения откройте Instagram → «API setup with Instagram business login». В раздел «Подключение» вставьте Instagram App ID и Instagram App Secret именно оттуда. Адрес возврата из панели вставляется в шаге «4. Настройте вход в Instagram от имени компании», в настройках входа, а не в поле вебхука шага 3. Для локальной панели откройте её как `http://localhost:4317`: Meta принимает `localhost` и сверяет адрес точно.

Пока приложение в режиме разработки, добавьте @iordani925 как Instagram Tester и примите приглашение в самом Instagram. После входа кнопка «Забрать последние комментарии» читает свежие посты. Сессия живёт около 60 дней и продлевается сама.

Права, которые запрашивает вход:

- `instagram_business_basic`
- `instagram_business_manage_comments`
- `instagram_business_manage_messages`

Готовый токен Страницы можно вставить в блоке «Токен вручную».

Чтобы ответы приходили сразу, в Meta укажите вебхук:

- URL: `https://<ваш-домен>/api/instagram/webhook`
- поле: `comments`
- проверочный токен показан в панели

Секрет приложения включайте, когда вебхук смотрит в интернет: без него подпись запроса не проверяется.

Автоответ по умолчанию выключен. Включите его, когда тон сообщений устроит. Сомнительные вопросы остаются на проверке. Повторно один и тот же комментарий не отвечается.

Пока приложение Meta в режиме разработки, отвечать можно комментариям людей, которые добавлены в роли приложения. Для всех подписчиков права нужно пройти в App Review.

## Каталог

Снимок карточек лежит в `data/catalog.json`. Кнопка «Обновить каталог» заново читает сайт и подменяет цены только после успешной загрузки. Телефон в ответах про доставку: 8 800 222-32-13, пн–пт, 9:00–18:00.
